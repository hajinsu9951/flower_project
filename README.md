# 사람이 꽃보다 아름다워

**대전대신고등학교 × 대전맹학교** — 2026학년도 장애인식개선 학생동아리 프로젝트 웹페이지

시각장애 학생과 비장애 학생이 함께 기획하고 함께 운영한
「장애공감 문화확산과 진로 융합 프로젝트」(2026. 7. 20. ~ 8. 21.)의 기록입니다.

## 구성

| 항목 | 내용 |
|---|---|
| 프로젝트 배경 | 개별적 모델과 사회적 모델, 장애 감수성 |
| 프로그램 | 황톳길 걷기, 십시일반 수학 아카이브, 진로·진학, Audio Book Garden, 아트 콜라보, 다시봄 시리즈 |
| 훈맹정음 체험 | 한글을 입력하면 점자 표기와 유니코드 점자를 보여 주는 변환기 |
| 동화책 | 학생들이 만든 6권 · 196쪽 전문 뷰어 |
| 교육지도안 | 학생이 직접 설계한 TPACK·AI-IBL 기반 수업 설계안 2편 |

## 접근성

이 페이지는 시각장애 학생과 함께 만드는 프로젝트의 기록이므로, 접근성을 설계의 중심에 두었습니다.

- 본문 색 대비 4.98 ~ 16.43 (WCAG AA 기준 4.5 상회)
- 제목 계층 건너뜀 없음, 모든 이미지에 대체 텍스트
- 글자 크기 5단계 · 고대비 모드 · 어두운 화면 모드 (설정 저장)
- 키보드만으로 전체 조작, 본문 바로가기, 3px 포커스 표시
- 동화책 뷰어: 쪽별 원문을 화면낭독기로 읽을 수 있도록 제공

## 실행

```bash
python -m http.server 8765
```

`http://127.0.0.1:8765` 로 접속합니다. 동화책 뷰어는 `books.json` 을 불러오므로
파일을 직접 여는 방식(`file://`)이 아니라 웹서버로 띄워야 동작합니다.

## 파일

- `index.html` — 웹 버전 (동화책 뷰어 포함)
- `사람이 꽃보다 아름다워 - 대전맹학교 연계 프로젝트.html` — 사진 내장 단일 파일 배포본
- `images/books/pages/` — 동화책 196쪽 이미지
- `books.json` — 동화책 쪽별 원문

## 안내

학생 명단과 연락처 등 개인정보는 포함하지 않았습니다.
사진에 등장하는 학생의 초상권과 관련해, 외부 공개 시에는 사전 동의 확인이 필요합니다.
